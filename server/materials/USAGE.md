## 详细使用说明

### 1. 组件信息查询

#### 查询组件基本信息
```markdown
# 示例：查询Button组件
文件位置: fusion-lowcode-materials/button.md

包含信息:
- 组件名称: Button
- 组件标题: 按钮
- 组件分组: 原子组件
- 组件分类: 通用
- NPM包: @alilc/lowcode-materials
```

#### 查询组件属性配置
每个组件文档都包含详细的属性表格：

| 属性名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| children | string | - | 按钮内容 |
| type | oneOf: primary \| secondary \| normal | normal | 按钮类型 |
| size | oneOf: small \| medium \| large | medium | 按钮尺寸 |
| disabled | bool | false | 是否禁用 |

#### 查询组件配置属性
低代码编辑器中的属性设置器配置：

| 属性名 | 标题 | 设置器 | 描述 |
|--------|------|--------|------|
| children | 按钮内容 | MixedSetter | 按钮文本内容设置 |
| type | 按钮类型 | RadioGroupSetter | 按钮类型选择 |
| icon | 图标 | IconSetter | 图标选择器 |

### 2. 常见查询场景

#### 场景1: 用户询问组件属性
**用户问题**: "Button组件有哪些属性？"

**查找步骤**:
1. 打开 `fusion-lowcode-materials/button.md`
2. 查看"属性配置"部分的"基础属性"表格
3. 提供完整的属性列表和说明

**回答模板**:
```
Button组件支持以下属性：

基础属性：
- children (string): 按钮内容
- type (oneOf): 按钮类型，可选值：primary | secondary | normal，默认值：normal
- size (oneOf): 按钮尺寸，可选值：small | medium | large，默认值：medium
- disabled (bool): 是否禁用，默认值：false
- loading (bool): 设置按钮的载入状态，默认值：false
- ghost (oneOf): 是否为幽灵按钮，可选值：true | false | light | dark，默认值：false
- onClick (func): 点击按钮的回调函数

配置属性：
- 支持图标设置器 (IconSetter)
- 支持混合设置器 (MixedSetter) 用于内容设置
- 支持单选组设置器 (RadioGroupSetter) 用于类型选择
```

## 故障排除

### 常见问题

#### 1. 找不到组件文档
**问题**: 用户询问的组件没有对应文档
**解决**: 
- 检查组件名称是否正确
- 查看是否在其他组件库中
- 确认组件是否存在

#### 2. 文档信息不完整
**问题**: 文档缺少某些属性或配置
**解决**:
- 检查源码中的meta配置
- 运行文档生成脚本更新
- 手动补充缺失信息

#### 3. 属性配置不匹配
**问题**: 文档中的属性与实际不符
**解决**:
- 对比源码和文档
- 更新文档内容
- 验证配置的正确性

### 调试技巧

1. **交叉验证**: 对比多个相似组件的配置
2. **源码查看**: 直接查看组件的meta.ts文件
3. **实际测试**: 在低代码编辑器中验证配置
