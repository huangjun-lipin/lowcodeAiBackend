## 属性配置

### 基础属性

| 属性名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| children | string | - | [object Object] |
| className | string | - |  |
| size | oneOfType: [object Object] | number | medium | 头像的大小 |
| shape | oneOf: circle | square | circle | 头像的形状 |
| icon | string | - | icon 类头像的图标类型，可设为 Icon 的 `type` 或 `ReactNode` |
| src | string | - | 图片类头像的资源地址 |
| onError | func | - | 图片加载失败的事件，返回 false 会关闭组件默认的 fallback 行为 |
| style | object | - |  |
