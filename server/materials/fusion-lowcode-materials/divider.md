## 属性配置

### 基础属性

| 属性名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| style | object | - | 自定义内敛样式 |
| children | string | 分隔符 | 文案 |
| dashed | bool | false | 是否为虚线 |
| direction | oneOf: hoz | ver | hoz | 线是水平还是垂直类型 |
| orientation | oneOf: left | right | center | center | 分割线标题的位置 |
