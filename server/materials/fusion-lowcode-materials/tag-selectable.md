## 属性配置

### 基础属性

| 属性名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| checked | bool | - | 标签是否被选中，受控用法 |
| defaultChecked | bool | - | 标签是否默认被选中，非受控用法 |
| disabled | bool | - | 标签是否被禁用 |
| onChange | func | - | 选中状态变化时触发的事件 Function(checked: Boolean, e: Event) => void |
| children | string | - | 内容 |
| style | object | - |  |
