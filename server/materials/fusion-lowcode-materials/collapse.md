## 属性配置

### 基础属性

| 属性名 | 类型 | 默认值 | 描述 |
|--------|------|--------|------|
| dataSource | array | - | 使用数据模型构建 |
| defaultExpandedKeys | arrayOf | - | 默认展开keys |
| expandedKeys | arrayOf | - | 受控展开keys |
| onExpand | func | - | 展开状态发升变化时候的回调 |
| disabled | bool | - | 所有禁用 |
| className | string | - | 扩展class |
| style | object | - | 组件接受行内样式 |
| accordion | bool | false | 手风琴模式，一次只能打开一个 |
| rtl | bool | - |  |
