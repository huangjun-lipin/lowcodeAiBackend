# 低代码物料文档

本目录包含了低代码平台中所有物料组件的详细文档，为AI助手提供准确的上下文信息。

## 目录结构

```
materials/
├── README.md                    # 本文件，总体说明
├── fusion-ui/                   # Fusion UI 组件库文档
│   ├── index.md                # Fusion UI 组件索引
│   ├── pro-table.md            # ProTable 组件文档
│   ├── pro-form.md             # ProForm 组件文档
│   └── ...                     # 其他组件文档
└── fusion-lowcode-materials/    # Fusion Lowcode Materials 组件库文档
    ├── index.md                # Fusion Lowcode Materials 组件索引
    ├── button.md               # Button 组件文档
    ├── input.md                # Input 组件文档
    └── ...                     # 其他组件文档
```

## 组件库概览

### Fusion UI (38个组件)
高级业务组件库，包含复杂的业务逻辑组件：
- **ProTable**: 高级表格组件，支持分页、排序、筛选等功能
- **ProForm**: 高级表单组件，支持复杂表单布局和验证
- **ProDialog**: 高级对话框组件
- **Filter**: 筛选器组件
- 等等...

### Fusion Lowcode Materials (98个组件)
基础原子组件库，提供丰富的UI基础组件：
- **原子组件**: Button、Input、Select等基础组件
- **信息输入**: Form、FormItem、各种输入组件
- **信息展示**: Card、Table、List等展示组件
- **信息反馈**: Message、Dialog、Notification等反馈组件
- **导航**: Menu、Breadcrumb、Pagination等导航组件
- **布局**: Grid、Layout等布局组件

## 文档标准

每个组件文档包含以下标准化信息：

### 1. 基本信息
- 组件名称 (componentName)
- 组件标题 (title)
- 组件分组 (group)
- 组件分类 (category)
- NPM包信息

### 2. 组件描述
- 组件功能说明
- 使用场景
- 主要特性

### 3. 属性配置
- **基础属性**: 组件的基本props配置
- **配置属性**: 低代码编辑器中的属性设置器配置
- 属性类型、默认值、描述等详细信息

### 4. 支持的功能
- 样式配置支持
- 事件配置支持
- 循环渲染支持
- 条件渲染支持

### 5. 容器配置
- 是否可作为容器组件
- 嵌套规则
- 子组件限制

### 6. 使用示例
- 代码片段 (snippets)
- 常见用法示例

## 使用说明

### 为AI助手提供上下文

当用户询问关于组件的问题时，可以参考相应的markdown文档：

1. **查找组件**: 通过组件名称或功能描述定位到具体组件
2. **获取详细信息**: 查看组件的属性配置、支持功能等
3. **提供准确答案**: 基于文档内容回答用户问题

### 组件查找方式

1. **按名称查找**: 直接查看对应的 `组件名.md` 文件
2. **按分类查找**: 查看各组件库的 `index.md` 文件，按分类浏览
3. **按功能查找**: 通过组件描述和分组信息查找相关组件

### 常见查询场景

1. **组件属性查询**: "Button组件有哪些属性？"
   - 查看 `fusion-lowcode-materials/button.md`

2. **组件功能查询**: "ProTable支持哪些功能？"
   - 查看 `fusion-ui/pro-table.md`

3. **组件分类查询**: "有哪些表单相关的组件？"
   - 查看各 `index.md` 文件的分类信息

4. **组件配置查询**: "如何配置Input组件的验证？"
   - 查看 `fusion-lowcode-materials/input.md` 的配置属性部分

## 更新和维护

### 文档更新流程

1. **组件变更**: 当组件库有更新时，需要同步更新文档
2. **脚本生成**: 使用 `server/scripts/` 目录下的脚本自动生成文档
3. **手动校验**: 检查生成的文档内容是否准确完整
4. **版本管理**: 记录文档版本和更新时间

### 自动化脚本

- `generate-fusion-ui-docs.js`: 生成Fusion UI组件文档
- `generate-fusion-lowcode-materials-docs.js`: 生成Fusion Lowcode Materials组件文档

### 文档质量保证

1. **完整性**: 确保所有组件都有对应文档
2. **准确性**: 文档内容与实际组件配置一致
3. **标准化**: 遵循统一的文档格式和结构
4. **可读性**: 文档内容清晰易懂，便于AI理解
